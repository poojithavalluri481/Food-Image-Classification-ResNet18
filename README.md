# Food-Image-Classification-ResNet18
Multi-class food image classification using ResNet-18 with Optuna-based hyperparameter optimization and sliding window detection.

Food Image Classification Challenge Dataset  
6003 images across 20 food categories.

## Model
ResNet-18 CNN

## Hyperparameter Optimization
Optuna framework

## Features
- Multi-class food classification
- Sliding window detection for plate images
- Confidence threshold filtering
- Visualization using circles

## Technologies
Python  
PyTorch  
Optuna  
OpenCV  
Matplotlib

## Results
Achieved high classification accuracy on 20 food categories.
